How a plan comes together

  1. Build the programme

    Add activity cards, each with a rain and wind tolerance and an indoor fallback.

  2. Check the forecast

    Fetch a real forecast; the exact snapshot is saved with your plan.

  3. Compare plans

    Rerun up to three plan versions against many slightly altered forecasts.

  4. Commit one plan

    The decision is added to a permanent log with the forecast it relied on.
